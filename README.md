# Bug Tracking and Resolution System

**BCA project submission**  
**Student:** Faiz Ahmad  
**Register No.:** 24SCSE1040301

A front-end bug and issue management prototype built using HTML5, CSS3 and vanilla JavaScript.

## Run the project

1. Extract this folder from the ZIP archive.
2. Keep `index.html`, `styles.css` and `app.js` in the same folder.
3. Open `index.html` in a modern browser.
4. Select **Report an issue** to create a record. Click any issue row to view details and update its status.

No build step, package installation, backend or external JavaScript library is required.

## Features

- Dashboard summary counts and status / priority distribution.
- Create and edit issue records with required-field validation.
- Search and filter issues by text, status and priority.
- Issue details, status updates, and confirmed deletion.
- CSV export.
- Responsive layout for desktop and narrow screen widths.
- Browser localStorage persistence.

## Scope note

This is a college-level, single-browser demonstration. Records are saved in the current browser profile and are not shared with other users or devices. Server-side login, permissions, central database storage, notifications, attachments, audit history and backup/recovery are future enhancements.
